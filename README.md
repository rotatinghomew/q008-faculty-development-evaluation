# 医学人文带教培训的实践迁移与续培判断

这是医学人文教学资料的本地分析工作区。带教老师培训模块与后续实践观察，均为虚构演练资料。

## 资料

`data/faculty-observations.csv` 是 UTF-8 编码的合成演练表。培训完成和行为观察分开记录；观察不是培训成效的预制判断。
`data/training-modules.csv` 提供与其关联的方案、情境或组织资料，用于理解主表事实的适用范围。

字段含义：教师代号、模块、培训版本、专科、岗位状态、观察来源、行为代号、日期、情境。

表中代号只用于连接同一份演练资料，不对应真实人员、院校或患者。数据没有预先计算的统计结论。

## 运行

需要 Python 3.11 或更高版本，无第三方依赖。运行基线检查：

```sh
python3 -m unittest discover -s tests -v
```

`src/humanities_analytics/inputs.py` 提供通用 CSV 读取入口，将每行作为字符串字段返回。
